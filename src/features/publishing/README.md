# 发布编辑器与草稿

回答、文章、提问和想法路由共用发布组件。发布接口仍由 `src/api/zhihu/` 提供，组件只维护编辑、预览、草稿和图片生命周期。

## 既有内容的无损编辑

`createPublishingDocument` 按原始 HTML 顶层结构划分正文。普通段落、二三级标题、粗体、斜体、链接、换行和可安全转换的代码只在 Markdown 往返后的结构与原文相同的情况下开放编辑。相邻普通块合并为一个输入区域，避免长正文挂载过多输入框。

表格、视频、公式、图片、带额外属性或样式的节点、列表、引用、复杂嵌套结构，以及含字面 Markdown 标记而无法安全往返的段落，都作为锁定原块展示。未修改的普通块及锁定块在提交时保留原始 HTML 字符串；不会先把整篇正文转换成 Markdown。用户可以修改开放区域、在文末新增内容，也可以在确认后主动移除原块。锁定块的内部结构暂不提供编辑；需要修改该结构时，应使用知乎官方编辑器。预览由统一的 `ZhihuContent` 渲染，提交保留的 HTML 与预览渲染过程独立。

恢复回答草稿时会比较草稿的原始 HTML 与当前线上原始 HTML。两者不同则暂停编辑和提交，用户必须明确选择恢复旧草稿（后续保存可能覆盖线上修改），或删除旧草稿及媒体副本并使用线上版本。

## 草稿与账号

SQLite migration 4 新增 `publishing_drafts`。草稿按已绑定账号、创作类型和目标内容隔离：新创作使用 `new` 目标，回答使用问题和回答标识。登录尚未获得账号身份时不建立草稿桶，也不会退回游客桶。切换账号时立即隐藏上一账号内容；移除账号会清理它的草稿与媒体目录，并通过世代标识阻止迟到保存重新创建已删除数据。

修改后等待 600 ms 自动保存，进入后台时立即保存。页面卸载前也会将尚在等待自动保存的编辑写入原账号。退出未完成编辑时可选择继续编辑、保存并离开或放弃草稿。保存失败会保留页面并提供重试，放弃时清理失败也不会直接离开。发布成功后删除草稿及媒体副本；如果本地清理失败，仍显示发布成功并提示不要重复发布。

已有草稿读取失败、损坏或版本暂不支持时会保留原记录，暂停编辑和保存，并提供重试读取，避免空白正文覆盖旧稿。用户也可在确认后主动删除这份本地草稿及图片副本并重新开始；清理失败时仍保持暂停。同账号重新登录也会重建编辑会话和媒体组件，旧会话的上传结果不会进入新会话，旧账号的确认框不会删除新账号草稿或关闭新页面。服务端提交尚未返回结果时暂停离开操作，确认成功或失败后再继续，避免迟到的发布结果误关后续页面。

自动保存的草稿保存在设备本地。想法编辑页额外提供“保存到云端草稿”和“读取云端草稿”：保存通过 `POST https://api.zhihu.com/content/drafts`，读取通过 `GET https://www.zhihu.com/content/plugin/{id}?action=pin`，解析返回的 `draft_plugin`，没有草稿时使用 `online_plugin`。读取需确认，会替换当前编辑内容与图片；失败不修改本地编辑。新想法的云端草稿 ID 随本地草稿保存，后续保存和发布复用该 ID；已发布想法使用其内容 ID 并传递 `isPublished: true`。本地草稿 JSON 版本升至 2，兼容读取版本 1，SQLite schema 不变。

自己的想法在详情菜单提供编辑和删除，编辑前核对当前登录账号与作者身份。标题、正文、图片和权限配置从插件数据恢复；普通正文块可编辑，复杂正文块沿用无损保留规则，图片可以移除或追加。未知媒体或损坏插件数据会暂停编辑并提示使用官方编辑器。删除经确认调用 `DELETE /pins/{id}`，成功后刷新相关列表。云端操作和发布期间暂停编辑与离开，旧账号的确认框和迟到结果不会覆盖新会话。

想法的插件元数据随本地草稿一起保存，恢复后保留原评论权限、可见范围和图片扩展信息。直接发布新想法也会先创建云端草稿并持久化 ID，发布失败重试复用同一草稿。

本地草稿正文和图片副本在应用沙箱中，目前没有单独的静态加密。恢复图片上传时，之前的上传中状态会变为可重试失败状态，不在打开页面时自动发送。

## 图片上传与清理

选图后先复制到当前账号和草稿的持久目录，不依赖系统临时选图 URI。每个草稿最多保留 9 张图，同时上传最多 3 张。失败项保留本地副本，可以逐项重试或移除；有上传中或失败项时暂不允许提交，以免静默漏图。重试有同步提交锁，连续点击不会重复上传。

移除项会取消其请求并删除所属副本；已插入正文的本次上传图片会同时移除对应生成的 Markdown。页面卸载会取消上传和轮询，旧账号、已移除项或已卸载页面的迟到结果不会插入正文。选择保存草稿离开时保留副本供下次重试；发布成功、放弃草稿和移除账号时清理目录。清理仅允许操作本仓储生成的目录与合法文件名，不删除其他来源的文件。

## 验证

以下专项回归覆盖安全往返、原块主动移除、账号与修订隔离、保存失败的离开行为、恢复上传、单项重试、取消和上传并发上限：

```bash
npm test -- tests/publishing.test.ts tests/publishingDocument.test.ts tests/publishingDocumentEditor.test.ts tests/publishingDraft.test.ts tests/publishingDraftRepository.test.ts tests/publishingEditor.test.ts tests/publishingMedia.test.ts tests/imageUploadCancellation.test.ts --runInBand
```

真实知乎提交、系统选图权限、原生文件复制/取消及 SQLite 迁移仍需使用测试账号在目标平台验证；测试只使用合成正文、账号和文件 URI。
