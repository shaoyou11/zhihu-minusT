# 知乎 minusT

基于上游 0.9.3，个人仓库主分支为 `main`，另保留 `custom/minusT` 开发分支。

- 应用显示名为“知乎 minusT”，沿用原版安装标识 `com.huamu013.ZhihuMinusMinus` 和原签名记录，作为覆盖更新保留原应用数据。
- 回答、问题、文章与想法详情的顶部导航采用模糊透明背景，覆盖状态栏区域；系统开启“降低透明度”时使用实色背景。
- 回答、文章与想法详情底栏贴近底部安全区。向下阅读时随滚动收起，反向滚动立即恢复；顶部回弹和底部回弹不累计隐藏距离。恢复阅读位置不会主动隐藏底栏。
- 保留上游版权、源链接和功能；应用内更新指向个人仓库。

## 开发与验证

依赖使用 `npm ci`，质量检查使用 `npm run check`。显示名称和安装标识修改后，运行 `npx expo prebuild --platform ios --no-install` 验证原生配置。生成的原生目录不提交。

后续同步上游时保留本分支的定制，逐项处理冲突。构建缓存与安装包应放本机缓存目录，避免 iCloud 扩展属性影响签名。GitHub Actions 在推送 main 或手动触发后执行质量检查、iPhone Release 编译、包校验和发布；构建号从 101 起自动递增。云端发布不运行模拟器编译；本地按需使用模拟器验收。

真机验收：在 iPhone 18 Pro Max / iOS 27 上检查浅色、深色、降低透明度、长正文、底部回弹、反向滚动、横向切换回答，以及收藏/评论/更多按钮。类型检查与单元测试不能代替真机视觉验收。

## 自签签定制关联

自签签显示个人仓库、main 定制分支及上游监测来源。单独检查可触发 `minust-ios.yml`：合并上游最新正式版，通过全部检查后保存源码并编译发布。每两天也自动检查一次；已发布的相同源码不重复编译。出现合并冲突或测试失败即停止，保留已发布版本。

## 首页交互补充

详情顶部使用与首页相同的渐变遮罩，并随阅读方向收起、恢复；文章、日报、回答、问题和想法共用导航组件。首页栏目在可用空间居中，超宽可横滑，选中项自动保持可见。设置中的“隐藏广告折叠提示”默认开启，只隐藏命中推广规则的占位和内容，质量及正则过滤仍遵循原来的折叠设置。设置版本升级到 19。

## 紧凑底栏与评论浮层

详情底栏按内容宽度居中，不再铺满整行；统一高度 48，保留现有操作。评论及楼中楼使用系统 formSheet，两档高度，支持拖动展开、下拉关闭与页面内输入回复；正文保持在底层，不重建阅读位置。评论首层提供关闭按钮，楼中楼提供返回评论按钮。所有现有评论入口共用此呈现方式。无新增依赖或原生配置。

## 键盘与底栏收起修正

评论和楼中楼引入本地 iOS 模块 `zhihu-keyboard-anchor`，用 UIKit `keyboardLayoutGuide` 在浮层自身坐标计算键盘遮挡，取代浮层内的 JS 窗口坐标测量。Android 及没有原生模块的预览环境保留原测量路径。模块通过 Expo 本地模块自动链接，新增后需 prebuild。

详情阅读底栏向下阅读时收为左下角的圆形展开按钮，反向滚动或点击即可展开；点击展开会停止旧惯性滚动继续收起，切换内容重置展开状态。展开和收起使用同一套薄玻璃材质，支持降低透明度。投票等内部状态不因收起而重建。

## 首页导航材质

顶部栏目条改用超薄系统模糊材质，降低整条背景的白色覆盖，去掉外轮廓边框并减淡选中项底色。保留居中、横向滚动和搜索入口；深色模式及系统降低透明度分别适配。

## 顶部色层、底栏变形与段落手势

首页栏目条移除单独的染色底板，保留选中项、居中与横向滚动，避免状态栏和栏目区出现两层底色。

详情底栏在同一个玻璃表面内连续收窄并移向左下角，文字先淡出，再露出展开图标。滚动停止时收拢或恢复到完整状态，反向滚动与点击均可中途展开；系统减少动态效果时遵循系统设置。

划线段落单击不再弹出操作，长按才显示段落操作；滚动或取消触摸会取消等待。链接、图片及普通文字选择保留各自手势，双击仍由原阅读快捷操作处理。iOS、Android 和网页排版共用此触发规则；原生模块改动须重新编译安装。

## 首页状态栏色层修正

首页状态栏安全区和栏目条共用运行时页面底色，覆盖范围包含栏目两侧；首页不再叠加全局卡片色渐变模糊，因此浅色、深色及阅读背景切换时不会重新形成上下两层底色。状态栏区域仍遮住经过的列表内容，栏目条保留原有滚动收起和横向切换；详情等其他路由的顶部安全区沿用原遮罩。

回归测试覆盖首页与详情/设置之间往返、运行时主题和阅读背景变化、安全区高度更新及无顶部安全区的情况。透明叠层与滚动后的实际观感仍须真机验收。

回答、文章和想法详情的全局底部遮罩只覆盖系统安全区，不再向上叠到阅读操作栏，避免重复染色和遮住操作文字；首页及其他路由保持原渐变范围。测试覆盖路由往返、横竖屏安全区高度变化和无底部安全区的情况。

## 阅读操作栏计数与收放修正

- 回答和文章的赞数保留完整文本。操作栏单独测量内容的自然宽度，不再将收起途中受限的宽度当成下次展开宽度；按下任一位置时展开到可用宽度，原按钮仍执行原操作。极长计数或窄屏超出一行时，可横向滚动访问全部操作，不裁掉末尾按钮。
- 收起改为先淡出操作内容，再将同一玻璃表面缩为左下角图标；展开按相反顺序进行。连续按下和旧滚动惯性不会立刻重新收起，减少动态效果设置继续有效。
- 阅读栏使用低强度基础明暗模糊和薄透明高光，避免系统材质内置的灰色遮罩；开启“减少透明度”时仍保留不透明回退。
- 自动测试覆盖完整大计数、自然宽度更新、收起前后宽度一致、按下展开且不吞掉原操作、超宽操作可滚动访问。真实 iPhone 的模糊采样、手势连贯性、系统动态字体与最终观感仍需安装新包后核对。

## 首页刷新响应修正

- 下拉刷新在提交原生刷新状态后立即启动首页请求，本地曝光记录并行读取，不再先等磁盘再发请求，也不再固定等待 500 毫秒。仍然只重置当前查询并请求第一页，取消旧分页请求；连续下拉合并为同一次刷新。
- 刷新期间保留当前内容，失败或离线暂停时仍可阅读并重试；新内容成功返回后替换旧列表。账号或查询条件变化会隔离旧快照与刷新任务，旧任务结束不会关闭新任务的指示器。
- 回归测试覆盖分页取消与迟到结果、并行本地读取、首屏请求数量、失败重试、离线恢复、启动缓存、账号切换、立即完成及卸载清理。真实知乎网络耗时和 iPhone 下拉回弹、离线后恢复的最终表现仍需安装新包后验证。
