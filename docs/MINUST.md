# 知乎 minusT

基于上游 0.9.3，个人仓库主分支为 `main`，另保留 `custom/minusT` 开发分支。

- 应用显示名为“知乎 minusT”，安装标识为 `com.shaoyou11.zhihuminust`，可与原版共存；原版登录和阅读记录不会自动迁入。
- 回答、问题、文章与想法详情的顶部导航采用模糊透明背景，覆盖状态栏区域；系统开启“降低透明度”时使用实色背景。
- 回答、文章与想法详情底栏贴近底部安全区。向下阅读时随滚动收起，反向滚动立即恢复；顶部回弹和底部回弹不累计隐藏距离。恢复阅读位置不会主动隐藏底栏。
- 保留上游版权、源链接和功能；应用内更新指向个人仓库。

## 开发与验证

依赖使用 `npm ci`，质量检查使用 `npm run check`。显示名称和安装标识修改后，运行 `npx expo prebuild --platform ios --no-install` 验证原生配置。生成的原生目录不提交。

后续同步上游时保留本分支的定制，逐项处理冲突。构建缓存与安装包应放本机缓存目录，避免 iCloud 扩展属性影响签名。GitHub Actions 在推送 main 或手动触发后执行质量检查、iPhone Release 编译、包校验和发布；构建号自动递增。不运行模拟器编译。

真机验收：在 iPhone 18 Pro Max / iOS 27 上检查浅色、深色、降低透明度、长正文、底部回弹、反向滚动、横向切换回答，以及收藏/评论/更多按钮。类型检查与单元测试不能代替真机视觉验收。
